Meie idee

Visit Tartu on veebileht, mis tutvustab Tartu vaatamisväärsusi. Tahame, et turistid ja uued tudengid leiaksid ühest kohast üles linna põnevamad paigad: ajaloo, looduse ja teaduse. Vaatamisväärsusi saab kategooria järgi filtreerida.

Leht koosneb kolmest osast: pealeht, vaatamisväärsused ning kaart ja info.
